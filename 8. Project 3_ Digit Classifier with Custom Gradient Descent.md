Implement Matrix Multiplication for the feed-forward layers: Feed-forward networks (FFNs) in machine learning —particularly in the Transformer architecture—process data via two linear transformations separated by a non-linear activation. The mathematical formulation is defined by matrix multiplication, expanding the input to a higher dimension, applying non-linearity, and compressing it back to its original size.

1. Mathematical Formulation: For an input matrix X in RB * S * d where B is batch size, S is sequence length, and d is the embedding dimension): FFN(X)=max (0,XW1+b1)W2+b2

Step 1: Linear Expansion: The input is projected into a higher-dimensional space (often 4 times the size of d to capture more complex features.Weight Matrix: W1 in Rd * dff
Bias Vector: b1 in RdffH1=XW1+b1

Step 2: Non-Linear Activation: A non-linear function (like ReLU or GELU) is applied element-wise to break linearity: A=ReLU H1

Step 3: Linear Compression: The expanded features are projected back down to the original dmodel dimensionality.

* Weight Matrix: W_2 in Rdff * dmodel
* Bias Vector: b2 in Rdmodel Output=AW2+b_2

2. Implementation with NumPy: Here is the implementation of the complete feed-forward layer using NumPy's matrix multiplication operator @:

import numpy as np

def feed_forward_layer(X, W1, b1, W2, b2): # Step 1: Linear Expansion

    # X shape: (batch_size, seq_len, d_model)

    # W1 shape: (d_model, d_ff)

    hidden_pre = np.matmul(X, W1) + b1 # Step 2: Activation (ReLU)

    hidden_post = np.maximum(0, hidden_pre) # Step 3: Linear Compression

    # W2 shape: (d_ff, d_model)

    output = np.matmul(hidden_post, W2) + b2    

    return output

Implement Backpropagation using the Chain Rule to update weights.

Backpropagation updates the weights of a neural network by calculating the gradient of the loss function with respect to each weight using the calculus chain rule, allowing the network to learn via gradient descent. 

Below is the complete mathematical derivation and matrix-based formulation to implement backpropagation for a neural network layer.  

1. Define Network Architecture: To understand how the chain rule propagates backward, we track a single forward step through a dense network layer l. Let: 

* al-1 = activation input from the previous layer.
* Wl = weight matrix for the current layer l.
* bl = bias vector for the current layer l.
* σ = element-wise activation function (such as Sigmoid or ReLU).

The pre-activation linear combination zl and the final activation output al are calculated as:

zl = Wl al-1 + bl 

al = Σ(zl) 

2. Apply the Chain Rule: Our ultimate goal is to find how a tiny change in a specific weight matrix Wl affects the final scalar loss L. Because Wl directly influences zl, which influences al, which ultimately impacts L, we unpack this composite function using the multivariate chain rule: L/Wl = L/zl • zl/Wl

* To make this computationally elegant, we isolate the error vector (often denoted as Δl) for layer l: Δl = L/zl 
* Using this notation, the final gradient needed to modify the weights is expressed as
  L/Wl = Δl • zl/Wl

3. Compute Local Derivatives: We evaluate the individual derivatives making up the chain rule equation piece-by-piece. 

Derivative of the Linear Step: zl/W1

Looking at the equation zl = Wl al-1 + bl, the derivative of the matrix vector product with respect to the weights isolates the input layer activation: zl/Wl = (al-1)T 

Base Case: Output Layer Error (ΔL): At the final layer L, the error is calculated by multiplying the derivative of the cost function by the derivative of the activation function: ΔL = L/ zL = L/ aL Σ'(zL) 

Inductive Step: Hidden Layer Error (Δl): For any hidden layer l, its error depends on the error of the subsequent layer l+1. Applying the chain rule backwards yields: Δl = L/ zl = (Wl+1)T Δl+1 Σ'(zl)

4. Formulate Weight Gradients: By substituting our evaluated local derivatives back into the main chain rule expression, we obtain the exact gradient vectors for both weights and biases at any given layer: 

L/ Wl = Δl (al-1)T 

L/ bl = Δl 

5. Execute Weight Update: With the gradients successfully calculated, we implement the optimization step using Gradient Descent. We shift the weights in the opposite direction of the gradient scaled by a learning rate (α) to minimize overall network error: 

Wl <- Wl - α L/ W^l

bl <- bl - α L/ bl

Summary of Equations:  Δ^l = L/ a^L Σ'(z^L) & for output layer  L \\ (Wl+1)TΔl+1 Σ'(zl) & for hidden layers  Wl <- Wl - αΔl(al-1)T

Principal Component Analysis (PCA) is the most common technique for dimensionality reduction. It is a mathematical procedure that transforms a set of correlated variables into a smaller set of uncorrelated variables called Principal Components. In machine learning, it is used to compress data by stripping away redundant information, making models faster and less prone to overfitting.

The Intuition: Rotating Your Perspective: Imagine a 3D scatter plot of data. PCA effectively rotates the axes of the plot so that the first axis (the First Principal Component) aligns with the direction where the data is most spread out.

* The first component captures the most variance (the most information).
* The second component captures the second-most variance, while being perfectly perpendicular (orthogonal) to the first.
* By focusing only on the first few components, you retain the shape of the data while drastically reducing the number of features.

The Step-by-Step Mathematical Process

* Standardize Scale the data so each feature has a mean of 0 and a variance of 1. 
* Covariance Matrix Calculate how every feature varies in relation to every other feature. 
* Eigen-decomposition Find the Eigenvectors (the directions of the new axes) and Eigenvalues (the magnitude of variance along those axes). 
* Sort and Filter Sort eigenvectors by their eigenvalues in descending order and keep the top k components. 
* Projection Multiply your original data matrix by the matrix of selected eigenvectors to get the new, reduced dataset. 

Why PCA is Powerful for Machine Learning

* Reduces Overfitting: By removing features that contribute little to the variance, you essentially filter out noise that the model might otherwise try to memorize.
* Solves the Curse of Dimensionality: Models struggle when they have too many features relative to the number of samples. PCA shrinks the feature space, allowing models to converge faster and more accurately.
* Visualization: PCA is the standard way to take high-dimensional data (like 100 features) and project it onto 2D or 3D space so you can actually see your data clusters.
When to Use PCA (and When Not To)
* Use it when: You have many highly correlated features, or your model is suffering from the Curse of Dimensionality and training is too slow.
* Avoid it when: Your data is inherently non-linear (in which case, use Kernel PCA or t-SNE), or if you need the final model to be highly interpretable (since the new components are abstract combinations of original features and lose their specific meaning).

import numpy as np

def pca_from_scratch(X, n_components): # 1. Standardize the data (Mean = 0, Std = 1)

    X_centered = X - np.mean(X, axis=0)

    X_scaled = X_centered / np.std(X_centered, axis=0) # 2. Compute the Covariance Matrix # Covariance is the dot product of the transposed matrix and itself, divided by (n-1)

    cov_matrix = np.cov(X_scaled, rowvar=False) # 3. Eigen-decomposition # Get eigenvalues and eigenvectors

    eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix) # 4. Sort components # eight returns them in ascending order, so we reverse them

    sorted_index = np.argsort(eigenvalues)[::-1]

    sorted_eigenvalues = eigenvalues[sorted_index]

    sorted_eigenvectors = eigenvectors[:, sorted_index] # Select the top 'n' components
    eigenvector_subset = sorted_eigenvectors[:, 0:n_components] # 5. Transform the data (Projection)

    X_reduced = np.dot(X_scaled, eigenvector_subset)

    return X_reduced, sorted_eigenvalues

Key Mathematical Steps Explained

np.mean and np.std: Essential because PCA is sensitive to the scale of the data. If one feature is measured in kilometers and another in millimeters, the latter will dominate the variance simply due to its scale.

* np.cov(..., rowvar=False): The covariance matrix tells us how every feature relates to every other feature. Setting row var=False ensures that columns are treated as variables.
* np.linalg.eigh: We use eigh instead of eig because the covariance matrix is symmetric. eigh is mathematically optimized for symmetric matrices, which is faster and more numerically stable.
* np.dot: This performs the matrix multiplication (projection) that maps your original data points onto the new, lower-dimensional space defined by the eigenvectors.

To implement Bayesian Linear Regression from scratch using NumPy, we update the Prior distribution of our weights into a Posterior distribution by incorporating the data.
The Math: Gaussian Conjugate Prior: We assume the weights w follow a Gaussian distribution. When we observe data, the update rules for the mean (μ) and covariance (Σ) of the weights are:

1. Posterior Covariance: Σpost = (Σprior-1 + Σ-2φ^Tφ)-1

2. Posterior Mean: μpost = Σpost (Σprior-1 μprior + Σ-2φTy)

Where: 

φ is your design matrix, 

Σ2 is the observation noise, and 

μ, Σ are the weight parameters.

import numpy as np

def bayesian_update(mu_prior, sigma_prior, X, y, α=1.0, beta=1.0):

    mu_prior: Mean of weights

    sigma_prior: Covariance of weights

    X: Input features

    y: Observed targets

    α: Precision of prior

    beta: Precision of noise (1/variance) # Precision matrix (inverse of covariance)

    sigma_prior_inv = np.linalg.i pinv(sigma_prior) # 1. Posterior Covariance: Sigma_post = (Sigma_prior-1 + beta * X.T @ X)-1

    sigma_post = np.linalg.pinv(sigma_prior_inv + beta * X.T @ X) # 2. Posterior Mean: mu_post = Sigma_post @ (Sigma_prior^-1 @ mu_prior + beta * X.T @ y)

    mu_post = sigma_post @ (sigma_prior_inv @ mu_prior + beta * X.T @ y)

    return mu_post, sigma_post # --- Usage Example ---

In deep learning, training on the entire dataset at once (Batch Gradient Descent) is computationally expensive and can get stuck in local minima. Mini-batch Gradient Descent is the industry standard because it balances speed with stability.

By using subsets of data, you introduce noise into the gradient estimation, which actually helps the model jump out of poor local minima and converge to more robust solutions.

The Intuition: Balancing Precision and Speed

* Batch: Uses all data. Very stable, but slow and memory-intensive.
* Stochastic (One sample): Very fast, but the gradient is extremely noisy (zig-zags).
* Mini-Batch: The Goldilocks zone. Uses a manageable subset (e.g., 32, 64, or 128 samples). It provides a stable gradient estimate while keeping computation efficient.

Implementation: The Generator Pattern: To handle batches efficiently in Python, you create a function that shuffles the data and yields subsets. This prevents the model from learning the order of the data.

import numpy as np

def get_batches(X, y, batch_size): # Shuffle indices to randomize the order

    indices = np.arange(X.shape[0])

    np.random.shuffle(indices) # Yield batches

    for start_idx in range(0, X.shape[0], batch_size):

        batch_indices = indices[start_idx : start_idx + batch_size]

        yield X[batch_indices], y[batch_indices] # Usage in your training loop:
