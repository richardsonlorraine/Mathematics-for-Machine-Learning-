Featured Projects

Principal Component Analysis from Scratch: Designed and implemented Principal Component Analysis using covariance matrices, eigenvalue decomposition and Singular Value Decomposition without relying on high-level machine learning libraries. The project demonstrates dimensionality reduction, image compression and variance preservation through mathematical implementation and visual analysis.

Bayesian Linear Regression: Implemented Bayesian regression from first principles to quantify predictive uncertainty through posterior probability distributions. The project demonstrates probabilistic reasoning, confidence interval estimation and uncertainty-aware prediction for reliable machine learning systems.

Neural Network from Scratch: Developed a fully connected neural network using only NumPy, implementing forward propagation, activation functions, backpropagation and gradient descent manually. The project demonstrates an understanding of optimisation, numerical computation and the mathematical foundations of deep learning.

Predictive Maintenance through Residual Analysis: Designed a regression-based anomaly detection system capable of identifying abnormal machine behaviour using statistical residual analysis. This project illustrates how classical machine learning techniques can be applied to industrial monitoring and predictive maintenance.

Regularisation and Model Selection: Investigated Ridge and Lasso regression together with K-Fold Cross-Validation to analyse the bias-variance trade-off, improve generalisation and perform automated feature selection through mathematically justified optimisation.

Mathematical Foundations Demonstrated: Throughout this portfolio, the following mathematical disciplines are applied directly to machine learning implementation:

Engineering Approach: Every project follows a consistent engineering methodology:

- Define the problem and objectives.
- Derive the underlying mathematics.
- Implement the algorithm from first principles.
- Validate results experimentally.
- Visualise performance and behaviour.
- Evaluate strengths, limitations and future improvements.

Professional Focus: The portfolio reflects an engineering philosophy centred on transparency, mathematical rigour and reproducibility. Rather than treating machine learning frameworks as black boxes, the projects demonstrate a detailed understanding of the algorithms that underpin modern artificial intelligence systems.

Collectively, these projects showcase the ability to bridge mathematical theory with practical software engineering, producing machine learning solutions that are explainable, reliable and suitable for real-world applications.
