Glossary of Terms

Activation Function: A mathematical function applied to the output of a neuron to introduce non-linearity into a neural network, enabling it to model complex relationships. Common activation functions include ReLU, Sigmoid, Tanh and Softmax.

Algorithm: A well-defined sequence of computational steps used to solve a problem or perform a calculation. Machine learning algorithms learn patterns from data to make predictions or decisions.

Anomaly Detection: The process of identifying observations that differ significantly from expected behaviour. It is commonly used in predictive maintenance, fraud detection and cybersecurity.

Backpropagation: The optimisation algorithm used to train neural networks by propagating prediction errors backwards through the network using the chain rule to calculate gradients.

Bayesian Inference: A statistical method that updates the probability of a hypothesis as new evidence becomes available using Bayes' Theorem.

Bias: The systematic error introduced when a model is too simple to capture the underlying relationships within the data, often resulting in underfitting.

Bias-Variance Trade-off: The balance between model simplicity and model complexity required to achieve good predictive performance on unseen data.

Classification: A supervised learning task in which a model predicts a discrete category or class label.

Confidence Interval: A statistical range that estimates where the true value of a parameter is likely to lie with a specified probability.

Covariance: A statistical measure describing how two variables vary together. Covariance matrices form the mathematical basis of Principal Component Analysis.

Cross-Validation: A model evaluation technique that repeatedly partitions data into training and validation sets to estimate model performance on unseen data.

Data Preprocessing: The process of preparing raw data for machine learning through cleaning, scaling, transformation and feature engineering.

Dimensionality Reduction: The process of reducing the number of input variables while preserving as much information as possible. Principal Component Analysis is one of the most widely used techniques.

Eigenvalue: A scalar representing the magnitude of variance captured by an eigenvector during matrix decomposition.

Eigenvector: A vector that defines the direction of maximum variance in a covariance matrix. Eigenvectors form the principal components used in PCA.

Feature: An individual measurable property or characteristic used as an input variable within a machine learning model.

Feature Engineering: The process of creating, transforming or selecting input variables to improve model performance.

Gradient: A vector of partial derivatives indicating the direction of the steepest increase of a function. Optimisation algorithms move in the opposite direction of the gradient.

Gradient Descent: An iterative optimisation algorithm that minimises a loss function by repeatedly adjusting model parameters in the direction of decreasing error.

Hyperparameter: A configuration value specified before model training begins, such as learning rate, batch size or regularisation strength.

Learning Rate: A hyperparameter controlling the size of each optimisation step during gradient descent.

Linear Algebra: The branch of mathematics concerned with vectors, matrices and linear transformations. It forms the mathematical foundation of modern machine learning.

Linear Regression: A supervised learning algorithm used to model the relationship between one or more independent variables and a continuous target variable.

Loss Function: A mathematical function measuring the difference between predicted values and actual observations. Training aims to minimise this value.

Machine Learning: A field of artificial intelligence that develops algorithms capable of learning patterns from data to make predictions or decisions without explicit programming.

Matrix: A rectangular arrangement of numbers used to represent datasets, transformations and model parameters.

Model: A mathematical representation learned from data that is used to generate predictions or classifications.

Neural Network: A computational model consisting of interconnected layers of artificial neurons that learn complex relationships through optimisation.

NumPy: A Python library providing efficient numerical computation, multidimensional arrays and linear algebra operations.

Optimisation: The process of finding model parameters that minimise a chosen loss function while maximising predictive performance.

Overfitting: A modelling error where a model learns noise within the training data, resulting in poor performance on new, unseen data.

Posterior Distribution: In Bayesian statistics, the updated probability distribution obtained after combining prior beliefs with observed evidence.

Principal Component Analysis (PCA): A dimensionality reduction technique that transforms correlated variables into a smaller set of orthogonal principal components while preserving the greatest possible variance.

Probability Distribution: A mathematical function describing the likelihood of possible outcomes for a random variable.

Python: A high-level programming language widely used for machine learning, data science and scientific computing.

Regularisation: A collection of techniques that reduce overfitting by penalising model complexity. Common methods include Ridge (L2) and Lasso (L1) regularisation.

Residual: The difference between an observed value and the value predicted by a model.

Ridge Regression: A regularised regression technique that penalises large coefficient values using the squared magnitude of the weights.

Lasso Regression: A regularised regression technique that performs automatic feature selection by shrinking some model coefficients to exactly zero.

Singular Value Decomposition (SVD): A matrix factorisation technique used for dimensionality reduction, data compression and numerical optimisation.

Softmax: An activation function that converts raw model outputs into probability distributions across multiple classes.

Statistical Inference: The process of drawing conclusions about populations using observed sample data.

Supervised Learning: A machine learning approach in which models learn from labelled training data to predict known outputs.

Tensor: A multidimensional mathematical array used to represent data within deep learning models.

Underfitting: A modelling error where a model is too simple to capture meaningful relationships within the data.

Uncertainty Quantification: The process of measuring and communicating confidence in model predictions, often using probabilistic methods.

Variance: A statistical measure describing the spread of data around its mean. In machine learning, excessive variance often indicates overfitting.

Vector: A one-dimensional mathematical object used to represent features, weights or directions within linear algebra and machine learning.

Weight: A numerical parameter learned during model training that determines the influence of an input feature on a model's prediction.
